# Go Testing

Test observable behavior, boundary cases, and error paths. Prefer table-driven
tests when cases share a shape. Run focused package tests while iterating and
`make check` before completion. Add bounded fuzzing for parsers and untrusted
input; commit minimized fuzz findings as regression cases.
