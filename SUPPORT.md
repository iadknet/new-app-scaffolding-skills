# Support

## Getting help

Use this repository's documentation and the relevant scaffold's skill
instructions first. For reproducible problems, use the GitHub **Bug report**
form. For focused improvements, use the **Feature request** form. Include the
scaffold involved, the command you ran, and the smallest safe reproduction.

## What does not belong in support requests

- Suspected vulnerabilities, credentials, tokens, keys, or other secrets. Use
  the private reporting process in [SECURITY.md](SECURITY.md).
- General-purpose application-design or framework support that is outside a
  scaffold's documented scope.
- Requests requiring an existing application to be shared publicly. Reduce the
  report to a safe, minimal reproduction instead.
